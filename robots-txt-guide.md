# Robots.txt Guide

The robots.txt file provides crawling instructions for search engine
crawlers.

## Basic Example

User-agent: *
Allow: /

Sitemap: https://example.com/sitemap.xml

## Block a Directory

User-agent: *
Disallow: /private/

## Important

Robots.txt should not be treated as a replacement for authentication


or access control.

Always test changes before deploying them.
