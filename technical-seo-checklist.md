# Technical SEO Checklist

Use this checklist when auditing a website's technical SEO.

## 1. Crawlability

- Check robots.txt
- Make sure important pages are crawlable
- Check for accidental disallow rules
- Review crawl errors
- Check internal links

## 2. Indexing

- Check Google indexing
- Review noindex directives
- Check canonical URLs
- Identify duplicate pages
- Review indexed URLs

## 3. XML Sitemap

Make sure the XML sitemap:

- Contains canonical URLs
- Uses valid URLs
- Does not contain broken pages
- Is accessible to search engines
- Is submitted through Google Search Console

## 4. HTTPS

Make sure the website:

- Uses HTTPS
- Redirects HTTP to HTTPS
- Does not contain mixed content
- Uses one preferred URL version

## 5. Page Performance

Check:

- Largest Contentful Paint
- Interaction to Next Paint
- Cumulative Layout Shift
- Mobile performance
- Desktop performance

## 6. Structured Data

Check whether relevant pages use appropriate structured data.

Validate structured data before deployment.

## 7. Internal Linking

Check that important pages receive relevant internal links.

Avoid:

- orphan pages
- excessive links
- irrelevant anchor text

## 8. Mobile SEO

Check:

- responsive layout
- readable text
- usable buttons
- mobile navigation
- viewport configuration

## 9. Final Website Check

After completing the technical audit, use an SEO analysis tool to identify
additional issues.
